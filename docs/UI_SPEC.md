# RustFRP 界面约定

> 2026-10-15 单 token 管理入口：Web 与桌面只显示“管理服务器、管理 token、连接”。Web 默认当前服务器，桌面默认本机管理地址；旧 local_mode 偏好不能跳过管理连接页。认证成功进入相同概览与管理菜单，不显示多管理员/API Token 管理页面。管理连接设置只说明配置文件、切换服务器和断开连接。原有本机 Agent 工具属于桌面高级维护，不再作为普通使用流程。该规定替代本文历史“账号/密码登录、登录后接入此电脑”的入口约定。

本文是 Web 管理面板与桌面管理员控制台的 UI 规范。两个宿主共用 `rustfrp-ui/` 的 HTML、CSS 和 TypeScript；后续页面必须遵循本规范并保留既有业务交互。共享颜色、字号和圆角 token 位于 `rustfrp-ui/src/styles/`。

用户于 2026-10-11 明确要求参照 CC Switch 截图改为两栏。该要求替代此前的三栏布局约定。

- 宽屏：一个可折叠菜单与一个内容工作区；按用户最新要求展开宽度为 **160px**，收起 72px。
- 菜单：按用户最新的“避免拥挤”要求，行高改为 40px，主菜单行间距 6px，展开时行内水平留白 12px；图标 18px，图标与文字间距 12px；文字使用现有 `Type.body`（13px），未选中为常规字重。选中采用草绿淡底、1px 草绿半透明边框、草绿文字与 medium 字重，图标保留分类色；收起时保留同样的背景与边框。顶部品牌与折叠按钮下方留 24px 后进入主菜单，连接状态与系统设置在下部；收起菜单同样保持 40px 点击区域。
- 折叠时隐藏文字，保留图标、选中态及 tooltip；折叠偏好持久保存，控制台与本机模式共享。
- 展开侧栏底部的连接状态（状态圆点与“已连接控制器”或“本机模式”文字）作为整体水平居中；收起时继续隐藏。
- 客户端、节点、隧道、系统设置不再拥有固定中间栏：客户端和服务端节点列表与详情在内容工作区内切换，隧道筛选与设置分类放在顶部。
- 720px 以下保留单栏、底部导航、详情返回流程。
- Web 与桌面共用样式 token；字体大小、颜色和圆角通过 CSS 自定义属性维护，草绿作为主操作色。
- 浅色 / 深色、展开 / 收起、宽屏 / 窄屏均需验证；客户端 CRUD、隧道编辑、设置权限不能因布局调整失效。

验证命令：`make ui-test`、`make ui-cov`、`make ui-build`、`make ui-e2e`、`make ui-shots DIR=/tmp/rustfrp-two-column-shots`。

菜单顶部品牌区：logo 22px、名称使用常规 13px；展开时品牌区左边距 20px，与主菜单图标左侧对齐（菜单外边距 8px + 行内边距 12px）；桌面顶部留 44px，Web 留 24px。收起时整行隐藏品牌图形与名称，只显示水平居中的展开按钮。

展开/收起按钮使用共享 SVG 线条图标（侧栏轮廓配方向箭头），不使用文字箭头；图标 16px，按钮保持原有 20×24px 点击区域与对齐，悬停提示和可访问名称随状态切换为“收起菜单”或“展开菜单”，并提供 `aria-expanded` 状态。

## 管理页统一样式（2026-10-13）

- 菜单与页面名称：概览、节点管理、客户端、隧道管理、审计日志；左下角为系统设置，底部导航采用相同名称。
- 客户端、隧道、审计、接入令牌、API Token 和管理员使用统一表头、细分隔线和独立操作列；常规行高至少 64px，长文本最多两行并提供完整内容 tooltip。
- 客户端与隧道窄屏保留单列操作卡；审计及设置中的表格窄屏可横向滚动到操作列，不能挤压控件或丢失字段。
- 页面用图标、用途说明和真实数据摘要引导阅读。客户端详情按设备信息、连接与接入分组，宽屏双列、窄屏单列；访问者继续保留独立控制与加密/压缩标记。
- 配色复用现有 token：蓝色用于连接/地址与身份，绿色用于正常状态/隧道，橙色用于凭据和待处理状态，红色用于拒绝与异常。主操作继续使用草绿色；字段标签和正文保留中性色。
- 设置各分类均显示用途说明；管理连接、主题、版本与日志采用分组面板，设备接入凭据原文仍仅在创建成功时显示一次。
- 保留刷新/重试、角色权限、操作理由审计、隧道批量启停、设备迁移、配置导入导出、应用更新等已有交互。摘要注明当前加载范围，不把局部日志记录数称为系统总数。

## 概览指标卡

- 六个指标为在线客户端、运行中的隧道、待使用的接入令牌、当前连接、24 小时流量、控制器版本。控制器版本与其他指标采用相同卡片尺寸，不再独占整行。
- 按内容区可用宽度布局：≥1040px 六列、≥560px 三列、≥300px 两列、更窄时单列；卡片间距与换行间距均为 8px。常规字号下高度约 96px，不用大面积留白制造视觉重量。
- 页面内边距 16px；卡片内边距水平 12px、垂直 7px。图标放入 24px 淡色底块，标题使用 caption、数值使用 metric，辅助信息保留一行；长内容截断时可悬停查看全文。
- 客户端与流量使用蓝色，隧道与控制器使用草绿色，连接使用状态绿，待使用令牌使用橙色。主数值保持正文色，避免将装饰色误解成告警状态。
- 保留流量时间范围、客户端/隧道筛选和采样说明，入站/出站图例与图表颜色一致；无数据、刷新失败和未采样必须如实显示。

## 节点管理与节点详情

- 用户界面中的“节点”是 **服务端数据面节点 Edge**，负责客户端接入与隧道转发；客户端单独管理。内置节点与 Controller 同进程，独立服务端节点单独运行。保持内部 `node` API、模型与协议命名不变。
- 节点列表展示节点名称/类型、连接状态、客户端数量、公网接入地址、版本与服务能力，并提供明确的详情入口；用表头、行分隔和悬停反馈区分记录，不采用无边界的卡片堆叠。
- 内置服务端类型使用绿色，独立服务端类型使用蓝色；在线/运行中、离线、已停用必须同时有文字说明，不能只靠颜色判断。控制连接断开不等于已建立的隧道全部停止。
- 详情顶部展示节点名称、类型、状态和客户端数量；下方按运行状态、网络与接入、服务能力、身份与安全分组，内容宽度 ≥900px 双列，较窄时单列；说明和管理操作独立展示。
- 网络区保留公网地址、客户端接入端口、远程端口范围；能力区按已配置字段展示 HTTP、HTTPS、TCPMUX 和子域名能力；身份区保留节点 ID 与证书指纹。未配置/未上报显示明确占位，不能伪造能力或监控数据。
- 独立节点的重命名、启用/停用、删除采用已有权限与审计流程。内置节点说明其由 Controller 管理，不展示无效操作；只读账号明确说明权限限制。
- 客户端数量须区分“已接入”和“在线”口径，不能将服务端返回的接入总数标为在线数。

## 各管理页面的信息层级

| 页面 | 主要信息与呈现 |
|---|---|
| 客户端 | 列表含名称/标签、连接状态、系统/Agent 版本、所属服务端节点、最近在线与登录 IP、详情操作。详情包含连接概况、设备信息、连接与接入、隧道及访问者。 |
| 隧道管理 | 顶部保留状态筛选；列表含名称/类型、实际状态与错误、所属客户端/节点、公网入口与本地目标、选择及启停/编辑/删除操作。摘要区分当前筛选数和已加载总数。 |
| 审计日志 | 表格含时间、中文操作名/原始标识、操作人/来源 IP、目标资源、理由、结果；未知操作保留原始标识。注明“本次加载”，刷新与重试保持可用。 |
| 系统设置 | 分类在内容区顶部切换。管理连接、外观、关于和控制器日志采用分组面板，设备接入令牌采用表格。桌面系统集成和本机维护只在高级设置提供。 |
| 设备接入令牌 | 展示名称、创建信息、到期时间、真实状态、撤销操作；凭据原文只在创建时展示，与管理 token 分离。 |
| 管理认证 | 只使用服务端配置的一个管理 token；不提供账号、密码、多管理员或管理密钥签发页面。旧 API Token 仅作为既有自动化接口兼容。 |

## 共享控件与验证

- 普通管理首次使用只填写管理服务器和 `[admin].token`，验证成功直接进入概览。旧本机模式偏好不能绕过连接页，普通导航和断开连接不再写入旧 `local_mode` 设置。
- 桌面高级维护仍按真实设备身份判断接入状态，保留自动节点接入、直接恢复、手动凭据和独立 frpc 文件维护；这些操作与管理登录无关，不出现在登录页或主菜单。
- 本机连接设置默认只显示连接方式、接入地址与电脑名称，独立模式支持文件选择。程序路径、身份目录和证书折叠在“高级设置”，保留既有自定义值；一次性凭据只用于启动，不写入偏好。本机未配置时不展示空路径表格或无用的状态分类，主按钮保持可点击并引导配置。
- 工具栏和状态分类按钮保持同一行顶边与高度一致，首个按钮不得单独添加底部外边距；深浅色及宽窄窗口均检查。
- 全局下拉框与普通操作按钮统一最小高度 32px、13px 字号、1.45 行高、1px 边框和 6px 圆角；下拉框左侧留白 12px、右侧 32px，使用统一向下箭头，避免系统原生外观压缩高度。筛选栏按钮（包括流量时间范围）统一使用同样的高度与留白；弹窗下拉框共用全局规则。深浅色、悬停、禁用及键盘焦点复用主题 token；高对比度模式保留系统箭头。其他位置的紧凑操作按钮继续使用 26px 最小高度。

- 页头、操作按钮、徽标、表格、表单和对话框优先复用 `rustfrp-ui/src/components/` 中的共享 DOM 组件。图标不要代替必要的操作文字；仅图标按钮必须提供 tooltip。
- 复用共享组件以保持表头、内边距、行高和详情分组一致。详情内容宽度 ≥860px 双列，更窄时单列。
- 表格空间不足时提供横向滚动或切换窄屏卡片，操作按钮不能溢出、被压缩或挤到不可见区域。长地址/ID/错误原因通过 tooltip 保留全文；页面标题和副标题也应防止溢出。
- 颜色必须复用浅色/深色 token，不硬编码单一主题颜色；色彩重点放在图标底块、状态徽章、地址和能力，主体保持中性色，不堆叠高饱和背景或无意义动画。
- 验证宽窄屏、深浅色、菜单展开/收起、有数据/空状态/加载失败，以及所有受影响的真实操作路径；页面重排不能丢失按钮、理由确认、重复提交保护和成功反馈。
- UI 修改运行 `make ui-test`、`make ui-cov`、`make ui-build`、`make ui-e2e`，使用 `make ui-shots DIR=/tmp/rustfrp-management-shots` 检查真实字体截图，并在浏览器验证受影响的页面。行、函数、分支覆盖率最低门槛均为 90%。
- 本地预览使用仓库根目录 `./start_dev.sh`，Web 管理面板固定为 <http://localhost:9674>；内置 Edge 与独立节点接入分别绑定 `127.0.0.1:17000`、`127.0.0.1:17001`。修改后重新构建并强制刷新，检查实际页面是否已加载新资源。
