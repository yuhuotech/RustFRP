# RustFRP 界面约定

用户于 2026-10-11 明确要求参照 CC Switch 截图改为两栏。该要求替代此前的三栏布局约定。

- 宽屏：一个可折叠菜单与一个内容工作区；展开 200px，收起 72px。
- 菜单：行高 28px；图标 18px；图标与文字间距 8px；文字使用现有 `Type.body`（13px），菜单文字统一常规字重，选中只改背景与颜色。顶部品牌与折叠按钮，主功能在上部，连接状态与设置在下部。
- 折叠时隐藏文字，保留图标、选中态及 tooltip；折叠偏好持久保存，控制台与本机模式共享。
- 客户端、节点、隧道、设置不再拥有固定中间栏：客户端列表与详情在内容工作区内切换，节点直接展示内置节点，隧道筛选与设置分类放在顶部。
- 720px 以下保留单栏、底部导航、详情返回流程。
- `theme/tokens.dart` 维持原样：字体大小、颜色、圆角及草绿 action 均不修改。页面继续使用 `PageHeader` 与共享控件。
- 浅色 / 深色、展开 / 收起、宽屏 / 窄屏均需验证；客户端 CRUD、隧道编辑、设置权限不能因布局调整失效。

验证命令：`make app-test`、`make app-cov`、`make web-build`、`make app-shots DIR=/tmp/rustfrp-two-column-shots`。

菜单顶部品牌区：logo 22px、名称使用常规 13px；桌面顶部留 44px，Web 留 24px。收起时整行隐藏品牌图形与名称，只显示水平居中的展开按钮。
