# 桌面本机模式（当前实现）

登录页「管理本机」或控制台左下「本机模式」进入。可选受管接入（Controller 地址、设备名、首次接入令牌、可选 CA/指纹）或独立模式（选择本地 `frpc.toml`）。Release 桌面包自带 Agent 并在首次启动时复制到用户状态目录；也可指定替代 Agent 绝对路径。令牌不会持久化。

桌面 Release 包随应用携带同版本 Agent，默认路径缺少文件时会复制到用户状态目录并设为仅当前用户可执行。开发时可将 Agent 路径指向本仓库 `target/release/rustfrp-agent`；Agent 升级器尚未实现，已安装副本需由后续安装包/手工替换更新。

界面显示实际连接状态、进程、配置版本和已应用隧道数。隧道在管理员控制台配置。令牌不保存到偏好设置；设备身份由 agent 私有保存，不同控制器必须使用不同的状态目录。不要删除身份文件来处理普通断连。

macOS 首次完成身份保存后切换到用户 GUI 域中的 launchd 任务，状态目录里的服务定义不包含接入令牌。关闭窗口不停止隧道；重开应用复用同一进程。点击「停止」通过本地控制令牌取消 Agent，并卸载该临时任务。

桌面托盘支持显示/退出菜单和关闭到托盘；设置页可启用当前用户开机启动并控制连接状态通知。Linux / Windows 采用 detached 进程，平台无关逻辑与回环协议有自动化测试，但尚未完成两平台实机验收。应用内更新器和本地 frp 配置逐项编辑尚未完成。

本地控制协议参见 [LOCAL_CONTROL.md](../rustfrp-protocol/LOCAL_CONTROL.md)。本机与控制台共用 [两栏界面约定](UI_SPEC.md)。

本机状态页显示 Agent 本次运行的实时连接数、成功转发入站/出站负载累计；进程重启后归零。统计不上传 Controller 再次累计，Controller 历史仍以 Edge 为准。UDP 只统计数据报负载，TCP/HTTP/HTTPS 包含实际转发首部和 TLS 透传数据。旧 Agent 缺少 `traffic` 字段时显示升级提示；非法负数或错误类型拒绝解析。2026-10-12 全栈 E2E 已核对双向 300000 字节。`make bench-mem` Release 基准：100 条空闲连接 Edge 6.78 MiB / Client 7.12 MiB；20 次 512 KiB 回显后峰值 7.12 / 7.69 MiB，关闭后 7.14 / 7.70 MiB。

本机模式在 Agent 运行时提供「查看本机日志」弹窗，可刷新与选择复制，并用游标轮询新增日志、检测环形缓冲淘汰缺口。日志读取使用私有控制令牌，最多 128 条/条最多 512 UTF-8 字节；解析错误、超限、未运行与旧协议均明确报错。诊断快照可导出到状态目录，返回新文件路径；内容只包含版本、运行状态、累计统计、最近脱敏日志和限制说明，秘密、端点和路径相关日志整条隐藏；Unix 0600，不覆盖已有文件。详见 `rustfrp-protocol/DIAGNOSTICS.md`。
