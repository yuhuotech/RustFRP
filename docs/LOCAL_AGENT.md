# 桌面本机模式（当前实现）

登录页「管理本机」或控制台左下「本机模式」进入。填写 agent 二进制的绝对路径、Edge 地址（例如 `frp.example.com:7000`）、设备名、独立状态目录，以及首次接入的一次性令牌；可以指定 CA 证书。

二进制使用本仓库 release 构建或同版本安装产物。默认读取安装脚本的用户级路径；首次构建可直接填 `target/release/rustfrp-agent` 的绝对路径。

界面显示实际连接状态、进程、配置版本和已应用隧道数。隧道在管理员控制台配置。令牌不保存到偏好设置；设备身份由 agent 私有保存，不同控制器必须使用不同的状态目录。不要删除身份文件来处理普通断连。

macOS 首次完成身份保存后切换到用户 GUI 域中的 launchd 任务，状态目录里的服务定义不包含接入令牌。关闭窗口不停止隧道；重开应用复用同一进程。点击「停止」通过本地控制令牌取消 agent，并卸载该临时任务。没有注册开机启动。

Linux / Windows 采用 detached 进程，平台无关逻辑与回环协议已测，但尚未完成两平台实机验收。托盘、系统启动、自更新、日志页和本地 frp 配置编辑尚未完成。

本地控制协议参见 [LOCAL_CONTROL.md](../rustfrp-protocol/LOCAL_CONTROL.md)。本机与控制台共用 [两栏界面约定](UI_SPEC.md)。

本机状态页显示 Agent 本次运行的实时连接数、成功转发入站/出站负载累计；进程重启后归零。统计不上传 Controller 再次累计，Controller 历史仍以 Edge 为准。UDP 只统计数据报负载，TCP/HTTP/HTTPS 包含实际转发首部和 TLS 透传数据。旧 Agent 缺少 `traffic` 字段时显示升级提示；非法负数或错误类型拒绝解析。2026-10-11 真实 E2E 已核对双向 300000 字节，100 连接 release RSS：Edge 6.22 MB / Client 6.19 MB。

本机模式在 Agent 运行时提供「查看本机日志」弹窗，可刷新与选择复制。日志读取使用私有控制令牌，最多 128 条/条最多 512 UTF-8 字节；解析错误、超限、未运行与旧协议均明确报错。日志为当前进程最近记录，持续尾随尚未实现。诊断快照可导出到状态目录，返回新文件路径；内容只包含版本、运行状态、累计统计、最近脱敏日志和限制说明，秘密、端点和路径相关日志整条隐藏；Unix 0600，不覆盖已有文件。详见 `rustfrp-protocol/DIAGNOSTICS.md`。
