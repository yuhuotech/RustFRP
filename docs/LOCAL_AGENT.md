# 桌面本机模式（当前实现）

> 2026-10-15：普通管理统一使用服务器地址和 `[admin].token`，不需要在登录前接入/启动 Agent。下文描述的本机工具保留在“系统设置 → 桌面设置 → 本机维护（高级）”，用于已有独立或受管设备维护。管理 token 与本工具使用的设备一次性接入凭据互不通用。

仅需管理服务器时，在统一连接页输入地址和管理 token 即可。确需维护本机设备时，从“系统设置 → 桌面设置 → 本机维护（高级）”进入；可以选择节点、填写电脑名称后自动取得设备接入凭据并启动。设备接入使用原有权限、理由和审计，与管理 token 登录独立。

即使已经手动保存地址，没有实际接入身份时也仍显示「此电脑尚未接入」。点击「登录并连接此电脑」后完成登录，会直接进入节点选择，原先填错的端口由所选节点地址替换；不需要手工填写令牌。已有接入身份时点击「启动连接」直接恢复。管理员提供的手动凭据只通过「管理员手动接入」展开后使用。

不登录也可从登录页「管理本机」进入，经「连接设置」手动填写管理员提供的接入地址、电脑名称，再启动时提供一次性令牌；也支持选择本地 `frpc.toml` / YAML / JSON 文件。程序路径、身份目录及 CA/指纹折叠在「高级设置」，默认自动填写随包 Agent 与状态目录，自定义值仍保留。Release 桌面包自带 Agent 并在首次启动时复制到用户状态目录；令牌不会持久化。

桌面 Release 包随应用携带同版本 Agent，默认路径缺少文件时会复制到用户状态目录并设为仅当前用户可执行。开发时可将 Agent 路径指向本仓库 `target/release/rustfrp-agent`。CA-07 Agent 更新器已实现签名清单、Release 版本标记与二进制摘要校验、同目录替换/回滚，并通知桌面协调重启。Tauri 桌面更新器支持 GitHub Release / 国内镜像、Ed25519 清单验证、包摘要校验、下载进度和取消，以及 macOS / Windows / Linux 安装策略。缺少编译时可信公钥或 Release 仓库配置时会拒绝更新；真实签名 Release 仍未发布。

界面显示实际连接状态、进程、配置版本和已应用隧道数。隧道在管理员控制台配置。令牌不保存到偏好设置；设备身份由 agent 私有保存，不同控制器必须使用不同的状态目录。不要删除身份文件来处理普通断连。

macOS 首次完成身份保存后切换到用户 GUI 域中的 launchd 任务，状态目录里的服务定义不包含接入令牌。关闭窗口不停止隧道；重开应用复用同一进程。点击「停止」通过本地控制令牌取消 Agent，并卸载该临时任务。

桌面托盘支持显示/退出菜单和关闭到托盘；设置页可启用当前用户开机启动并控制连接状态通知。Linux / Windows 采用 detached 进程，平台无关逻辑与回环协议有自动化测试，但尚未完成两平台实机验收。独立模式可编辑完整 TOML/YAML/JSON 配置文本，保存前执行 Agent 校验并以暂存文件原子替换；编辑器以完整配置文件文本为单位，不提供逐字段表单。

本地控制协议参见 [LOCAL_CONTROL.md](../rustfrp-protocol/LOCAL_CONTROL.md)。本机与控制台共用 [两栏界面约定](UI_SPEC.md)。

本机状态页显示 Agent 本次运行的实时连接数、成功转发入站/出站负载累计；进程重启后归零。统计不上传 Controller 再次累计，Controller 历史仍以 Edge 为准。UDP 只统计数据报负载，TCP/HTTP/HTTPS 包含实际转发首部和 TLS 透传数据。旧 Agent 缺少 `traffic` 字段时显示升级提示；非法负数或错误类型拒绝解析。全栈 E2E 已核对双向 300000 字节。2026-10-12 `make bench-mem` Release 基准：空闲 Edge/Client 5.05/5.06 MiB；100 条连接 6.97/7.41 MiB；20 次 512 KiB 回显后 7.39/7.88 MiB，关闭后 7.41/7.89 MiB。

本机模式在 Agent 运行时提供「查看本机日志」弹窗，可刷新与选择复制，并用游标轮询新增日志、检测环形缓冲淘汰缺口。日志读取使用私有控制令牌，最多 128 条/条最多 512 UTF-8 字节；解析错误、超限、未运行与旧协议均明确报错。诊断快照可导出到状态目录，返回新文件路径；内容只包含版本、运行状态、累计统计、最近脱敏日志和限制说明，秘密、端点和路径相关日志整条隐藏；Unix 0600，不覆盖已有文件。详见 `rustfrp-protocol/DIAGNOSTICS.md`。
