# 本机诊断快照 v1

桌面从私有本机控制通道读取状态与最近日志，导出到当前状态目录的新 JSON 文件。只包含 `schema_version`、`agent_version`、`captured_at`、运行状态、双向统计、脱敏日志及限制说明。禁止包含接入令牌、发现令牌、公钥/私钥、身份文件、原始配置、控制器地址、本地路径或流量载荷。

日志至多 128 条，每条至多 512 UTF-8 字节；桌面再次脱敏，token/password/secret/authorization/private key 相关消息整条隐藏。目录与 IP 地址可能出现在错误日志中，诊断导出对含 `/`、`\\`、`:` 的日志整条隐藏，牺牲部分诊断细节保护端点和路径。JSON 最多 400 KiB，以新文件独占创建，不覆盖已有文件。Unix 文件权限 0600；Windows 使用当前用户状态目录的继承权限。快照不同时刻读取，不能声称原子一致。Agent 未运行或旧版本不支持日志时明确失败。
