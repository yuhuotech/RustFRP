# 流量统计协议（实现中）

本文件定义数据面计数与管理 API 的统一口径；当前 Edge 已有节点总计数及按隧道计数（TCP、UDP、HTTP/HTTPS 含首部），Controller 已按 5 秒采样写入分钟桶，并提供登录后的 `/api/v1/traffic` 历史查询和 overview 实时总量；共享管理 UI 已接入小时图表、24h/7d 切换、客户端/隧道筛选和实时连接/累计流量卡片。

## 计数口径

计数只在 Edge 转发边界产生，Client 不重复计数。`bytes_in` 为公网访问者发往本机服务的有效字节，`bytes_out` 为本机服务返回公网访问者的有效字节。TCP/HTTP/HTTPS 统计成功写出的字节，包含 HTTP 头和 TLS 透传数据，但不包含 RustFRP 控制协议、yamux/TLS 封装或 TCP/IP 头。UDP 统计成功转发的数据报负载，排除封装头，发送失败不计为已转发。

`connections` 是当前存活的转发连接；UDP 为当前存活的访问者关联。建立时增加，正常结束、错误、取消均减少。`connections_total` 是进程内累计成功建立次数，错误重试不重复增加。计数使用每代理固定大小原子变量；连接不另设定时器或统计线程。

## 采样与持久化

内置 Edge 的采样任务持有随机启动标识 `epoch`，代理登记时获得进程内唯一 `generation`。Controller 按 `(epoch, proxy, generation)` 求差；已知从零启动的新实例首份累计值计入桶，并标记观测缺口。同一实例若时间戳重复/回退且计数未变则不重复计数；若计数不同则报错且不确认回收，等待下次时钟前进后重试。外置 Edge 的控制流上传仍待实现，需增加单调序号，不可依赖远端墙上时钟判断顺序。热更新沿用代理身份的计数；删除后最后一份计数应先消费再移除。

分钟桶保存采样区间内成功转发的字节差值和连接峰值；这是采样期间的聚合，不能声称能精确还原任意毫秒边界。实时累计量不等于历史桶之和（启动首样本、异常退出、缺失采样可造成差异）。缺失桶在 API 中标记缺失，不能伪装为实际零流量。

内置 Edge 通过有界共享注册表采样，避免每连接事件消息。外置 Edge 后续使用控制流上传有界批次；单次代理数量和消息体沿用配置容量上限。聚合查询限定 24 小时或 7 天，SQL 先聚合再返回，24 小时与 7 天都按小时聚合，最多 168 个桶，不能把所有明细载入堆。缺失的整桶不返回，响应 `sampled_only=true`；小时内观测不足 60 个分钟或存在采样缺口时 `gap=true`。全节点的 `connections_peak` 是各隧道采样峰值之和，不能当作全节点瞬时并发峰值。历史保留 7 天，每轮每表最多删除 2048 行，删除与事务审计一起提交。

## 验收

- 保持连接打开时计数实时增加；双向流量分别断言。
- 正常断开、取消、I/O 错误后当前连接回零。
- TCP、UDP、HTTP Host 改写、HTTPS 透传均以真实转发校验。
- 重复样本、乱序、重启、热更新、删除、跨分钟及缺失采样边界。
- 查询时间范围、客户端/隧道权限、保留清理和数字上限。
- Rust 与 TypeScript UI 共用 JSON fixtures；面板浅/深、宽/窄真实图表验证。
- 默认计数不分配每连接容器；运行时复测内存，覆盖率不降基线。

## 当前注册表约束

单节点最多保留 1024 个代理计数条目。停止条目的最终累计值保留到采样器持久化成功后确认；存在持有计数的转发任务或累计值已改变时，确认不会移除条目。热更新和同名重连复用尚未确认回收的计数。回收后重新创建同名代理的累计值会从零开始，采样器必须将其作为新的统计实例（不能仅按进程 epoch 判断回退）。Controller 已在事务提交后按实例编号确认最终样本，采样失败不回收且记录错误后重试。独立 Edge（`Edge::bind` / CLI edge 模式）没有持久历史消费者，在现有事件循环每 5 秒回收无人持有的停止条目，节点总计数保留；不增加任务或线程。`bind_with_policy` 默认保留最终样本，调用方须提供消费者，Controller 已接入。独立 Edge 历史持久化与展示仍待后续本地管理能力。

## 已接入的 REST

`GET /api/v1/traffic?hours=24` 或 `hours=168`，可加 `tunnel_id=<id>`、`client_id=<id>`，同时指定时按交集过滤。沿用管理会话认证，viewer 可读取；非法范围返回 400，指定不存在的隧道返回 404。响应结构见 `fixtures/traffic-history.json`；`window_end` 是服务端当前小时的 UTC 毫秒时间，客户端据此保留缺失小时为空槽。面板可点击或悬停查看小时明细；缺失槽显示无采样，观测缺口显示标记，刷新失败但仍有旧结果时明确提示。`GET /api/v1/overview` 的 `traffic` 为本次 Edge 进程实时累计 `bytes_in/bytes_out/connections/connections_total`，不是今天的历史合计；重启后归零。硬中断可能丢失尚未采样的最后一段流量，采样间隔为 5 秒，面板不可将其描述为计费级精度。
