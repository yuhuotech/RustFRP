# 受管配置导入 / 导出

已实现接口：`POST /api/v1/clients/{id}/config/preview`，输入 frpc TOML/YAML/JSON，返回配置摘要、拟新增/修改/保持的隧道和兼容报告；`POST .../config/import` 重新校验并要求匹配预览摘要、明确接受报告和 reason，同事务写入/审计。只增改导入中出现的同名隧道，不删除未出现的资源。原始 source 保存以便导出未运行的字段；运行能力不足须逐项报告，不静默吞掉。认证/连接公共字段由管理面身份与节点设置代替，导出不包含设备密钥或接入令牌。上传不允许 includes、文件 tokenSource 或环境模板，以免读服务器文件或环境。最大 1 MiB、100 条代理；全部预检冲突后一起提交。
